# Salesgenie pricing — review build

Pricing-only build of the Salesgenie pricing prototype for stakeholder review.
It contains just the pricing page (options Current, B · Value-led and B3 · Value focused,
with the B3 grouping styles); search, scenarios and admin screens are not included.

Links:
- `/` opens B3 · Value focused
- `/?option=b` B · Value-led, `/?option=current` the current layout
- `/?groups=switch|glow|tray|tracks|tabs|spotlight|inline|tabsBorder|tabsGlow` B3 grouping styles

Run locally: `npm install && npm run dev`
